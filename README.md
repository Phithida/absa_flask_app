\# ABSA Flask Application

A Flask web application for analyzing accommodation reviews using Aspect-Based Sentiment Analysis (ABSA).



\## Technologies

\- Python

\- Flask

\- Natural Language Processing

\- Aspect-Based Sentiment Analysis

\- HTML/CSS



\## Project Overview

This academic project focuses on extracting aspects and sentiments from accommodation reviews and presenting the analysis results through a web application.



\## Project Structure

\- `app.py` — Flask application

\- `templates/` — HTML templates

\- `static/` — CSS and static files

\- `requirements.txt` — Python dependencies



Large trained model files and datasets are not included because of their file size.
